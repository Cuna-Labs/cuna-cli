# Runa CLI PRDs

This directory owns the product and engineering requirements for Runa CLI. It
contains 43 numbered product/engineering PRDs plus the `PRD-000` catalog.
`PRD-000-index.md` is the authoritative dependency graph and delivery order.

The documents are specifications, not evidence that a feature is implemented
or released. Every implementation claim must be bound to code, tests, an exact
artifact, and fresh release evidence.
